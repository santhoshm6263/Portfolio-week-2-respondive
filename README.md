# Portfolio-week-2-respondive
🌐 Responsive Portfolio Website
🔍 Project Overview
This project is a mobile-first responsive personal portfolio website designed to showcase my skills, projects, and design workflow.
It focuses on modern UI/UX principles, smooth animations, and adaptability across mobile, tablet, and desktop devices.
🎯 Objective
Build a fully responsive website
Practice mobile-first design approach
Improve UI/UX and frontend skills
Showcase projects and design thinking
Create a professional personal brand
👥 Target Audience
Recruiters & hiring managers
Internship providers
Designers and developers
Tech enthusiasts
🧠 Problem Statement
Many portfolio websites are not optimized for different screen sizes, leading to poor user experience.
This project aims to create a responsive and user-friendly portfolio that works seamlessly across all devices.
💡 Solution
Developed a responsive portfolio using:
Mobile-first layout
Flexible grids and layouts
Smooth animations
Interactive navigation
Dark/Light theme toggle
🌐 Key Features
📱 Fully Responsive Design (Mobile → Desktop)
🍔 Hamburger Menu for Mobile Navigation
🌙 Dark / Light Mode Toggle
✨ Scroll Animations using Intersection Observer
📊 Animated Skill Progress Bars
🎨 Modern UI with gradients and typography
🚀 Interactive Project Cards
